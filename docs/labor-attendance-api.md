# 人员信息 + 考勤标准接口说明

| 项 | 内容 |
|----|------|
| 版本号 | V1.0 |
| 更新日期 | 2026-07-31 |
| 状态 | 草稿 |
| 所属系统 | 工程数字化监管平台二期 |
| 模块名称 / 模块编码 | 人员实名制管理 / LABOR |
| 说明 | 平台输出标准化人员信息、考勤数据接口，由各项目子系统（考勤闸机配套平台）上报；不强制替换现场硬件 |

---

## 1. 对接原则

- **监管非业务替代**：平台不做一线人员档案填报/审批闭环，不走数字档案。
- **硬件不强制统一**：对接项目既有考勤闸机即可。
- **采集口径收窄**：仅四类数据；工资明细本期不采集。
- **轨迹不统一标准**：轨迹能力通过项目外链跳转自有系统，不纳入本接口强制字段。

---

## 2. 人员信息上报（Person）

建议接口：`POST /api/v1/labor/persons/sync`（批量幂等）

| 字段分组 | 字段 | 类型 | 必填 | 说明 |
|----------|------|------|------|------|
| 基本身份 | projectCode | string | 是 | 项目编码 |
| 基本身份 | personnelNo | string | 是 | 人员编号（项目内唯一） |
| 基本身份 | name | string | 是 | 姓名 |
| 基本身份 | phone | string | 否 | 手机号 |
| 基本身份 | idType | string | 是 | 证件类型 |
| 基本身份 | idNumber | string | 是 | 证件号码 |
| 基本身份 | gender | string | 否 | 性别 |
| 基本身份 | age | number | 否 | 年龄 |
| 基本身份 | unitName | string | 是 | 参建单位 |
| 基本身份 | workType | string | 是 | 工种/职务 |
| 基本身份 | personnelCategory | string | 否 | 管理人员/劳务人员/特种作业人员 |
| 基本身份 | entryStatus | string | 是 | 已入场/已退场 |
| 特种资质 | isSpecial | boolean | 否 | 是否特种作业 |
| 特种资质 | certNo | string | 条件 | 特种作业证书编号 |
| 特种资质 | certValidTo | date | 条件 | 特种作业资质有效期 |
| 安全教育 | safetyEducation[] | array | 否 | 三级安全教育记录 |
| 安全教育[].type | string | 是 | 如「三级教育」 |
| 安全教育[].trainDate | date | 是 | 培训日期 |
| 安全教育[].qualified | boolean | 是 | 是否合格 |

**不采集**：工资明细、计薪方式、合同金额等。

---

## 3. 考勤记录上报（Attendance）

建议接口：`POST /api/v1/labor/attendance/sync`

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| projectCode | string | 是 | 项目编码 |
| personnelNo | string | 是 | 人员编号 |
| recordDate | date | 是 | 考勤日期 |
| clockIn | datetime | 否 | 上班打卡时间 |
| clockOut | datetime | 否 | 下班打卡时间 |
| gateIn | string | 否 | 进场闸机 |
| gateOut | string | 否 | 出场闸机 |
| onSiteStatus | string | 否 | 在场/不在场（可由平台据打卡推算） |

班组级明细由项目自有系统维护，**不要求**向平台上报班组维度明细表。

---

## 4. 同步时效与看板

- 源数据对接成功后，监管看板**即时同步**展示。
- 指挥部看板仅展示：全局人数、工种占比、特种作业在岗、预警汇总等。

---

## 5. 黑名单与预警（说明）

- 企业级黑名单由平台维护；出现打卡记录时持续提醒责任人。
- 平台**无法**强制操控现场考勤机拉黑，需项目侧配合退场。
