# 处罚单台账与 Word 导出

页面入口：调度中心 → 处罚单，现有路由为 `#/coc-admin/penalty`，组件为 `src/coc/admin/AdminDispatchPenaltyList.vue`。本次依据用户提供的台账截图、三份 Word 模板及 2026-11-10 确认的责任单位、导出状态口径调整；菜单、路由和处罚单流转规则保持现状。

角色栏的“原型说明（模板下载）”提供[1112版需求变更PRD](../requirement-changes/requirements/Requirement_Changes_PRD_1112.docx)，以及处理中、待验收、已关闭（非手动关闭）的三份Word原模板。资料下载沿用每日调度检查的说明弹窗样式，保留原文件名和字节；台账逐条“导出”仍按处罚单状态填充对应模板。

## 实体与字段来源

处罚单仍以现有 `id` 为唯一标识，保存于 `coc-admin-dispatch-penalties`。项目主数据仍归项目信息管理维护。责任单位是关联回显，Word 是单条处罚单的导出副本，不新增持久化字段、业务实体、主子表或后端接口。

| 展示或导出内容 | 来源 | 处理方式 |
| --- | --- | --- |
| 编号、项目、类型、事由、指派人、时限、条款 | 现有处罚单字段 | 沿用原值及现有指派人展示方法 |
| 责任单位 | 关联项目的 `contractorUnit`（施工单位） | 优先项目 ID；其次按项目全称或简称精确匹配，兼容空格差异；多重匹配或无法匹配时显示 `--` |
| 下发日期 | `issueTime` | 只输出年月日，不包含时分秒；缺失时为 `--` |
| 违约金、上报结果、验收说明 | `amount`、`reportResult`、`acceptRemark` | 按对应状态模板填充，不以申诉意见替代验收说明 |
| 处罚单补充附件 | `attachments`，兼容 `snapshot` | 按 URL 去重；不混入上报结果附件或申诉附件 |

责任单位不取处罚单历史 `unit`、指派人组织或岗位，不把派生值写回原记录。项目无法对应主数据的历史单据继续显示 `--`，不推测施工单位。

## 台账与操作

- 筛选区、总数与新增、列表及分页统一放在白色内容卡片中。筛选区在上方，分隔线下方左侧显示实际总数，右侧显示“新增”。使用灰色表头、白色行、横向分隔线，操作列固定在右侧，文字按钮之间使用竖线分隔。
- 列顺序为：序号、编号、项目名称、类型、责任单位、事由、指派人、完成时限、条款、操作。状态用于筛选；金额、状态及黑榜信息仍可在原详情中查看。
- 关键字、状态、责任单位组合筛选；点击“搜索”或文本框内按回车才应用条件并返回第一页。关键字兼容原有编号、项目、类型、事由、指派人、时限、条款和金额搜索。
- “重置”清空筛选，恢复每页 10 条及第一页。分页支持每页 10、20、50、100 条，序号跨页连续；筛选后的总数来自实际记录。
- 较窄页面下筛选控件换行，表格允许横向滚动，操作列保持可见。页面沿用平台字体、颜色、共享适用角色栏及既有控件。

| 状态 | 台账操作 | 导出模板 |
| --- | --- | --- |
| 待下发 | 详情、编辑、下发、关闭 | 无 |
| 处理中 | 详情、导出、纳入黑榜 | 处理中 |
| 待验收 | 详情、导出、纳入黑榜 | 待验收 |
| 已关闭，验收或申诉通过关闭 | 详情、导出 | 已关闭（非手动关闭） |
| 已关闭，手动关闭 | 详情 | 无 |
| 申诉中 | 详情 | 无 |

兼容历史单据：明确 `closeType` 为 `manual` 的记录始终无导出；没有关闭类型但有验收时间、验收人或申诉通过结果的记录可以使用非手动关闭模板；只有关闭时间而无法确认关闭性质的历史记录不显示导出。新增、编辑、下发、关闭及纳入黑榜仍调用原有流程；导出只读取当前行。

## Word 模板与填充

原模板来自用户提供的“加项目名称”目录，工程内保存字节一致的静态资源。应用不会改写原模板。

| 模板占位符 | 处罚单字段 | 使用模板 |
| --- | --- | --- |
| 下发日期 | `issueTime` 的年月日 | 三类 |
| 编号 | `id` | 三类 |
| 项目名称 | `project` | 三类 |
| 处罚内容 | `penaltyContent` | 三类 |
| 条款 | `penaltyClause` | 待验收、非手动关闭 |
| 金额 | `amount` | 待验收、非手动关闭 |
| 上报结果 | `reportResult` | 待验收、非手动关闭 |
| 验收说明 | `acceptRemark` | 非手动关闭 |
| 处罚单补充附件 | 去重后的补充图片 | 三类 |

导出文件名为 `违约处罚通知单_<编号>_<状态>.docx`。金额沿用现有元单位，去除值末尾已有的“元/元整”再填入模板，避免重复单位；数值 0 保留。普通空值为 `--`。签字盖章和签字日期保留原模板留白，不自动填入姓名或当前日期。模板内“注意只取到日期，时分秒不显示”的填写说明不输出。

基于现有 JSZip 增量填充 Word 包，支持模板占位符分散于多个文字 run 的情况，保留特殊字符及正文换行。保留原样式、字体、页面尺寸、页边距、段落结构、签字区和附件分页；除正文 XML、图片所需关系、内容类型及新增媒体外，其余包条目保持原字节。

补充图片转为 PNG 后使用 Word 嵌入型图片（`wp:inline`），等比缩放并附文件名图注，按原模板从附件页开始排版。无图片时为 `--`；图片无法读取或不完整时显示失败，不生成缺图成功文件。模板静态资源会内嵌到构建后的单文件页面，导出不依赖业务接口。全过程不改写原处罚单或项目主数据。
