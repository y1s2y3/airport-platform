# 每日施工作业

页面入口：施工现场管理 → 施工作业管理 → 每日施工作业。路由为 `#/major-hazard/daily-work`，由 `src/views/majorHazard/DailyWorkView.vue` 加载 `src/coc/admin/AdminDailyWorkEntry.vue`。

标题旁的“原型说明（模板下载）”提供[1112版需求变更PRD](../requirement-changes/requirements/Requirement_Changes_PRD_1112.docx)和本轮Excel导出模板的原文件下载，沿用每日调度检查的说明弹窗样式。该入口与工具栏既有导入模板下载分别保留，下载文件名和内容与用户原件一致。

## 当前导出规则（2026-11-11）

依据用户本轮需求及确认的三张Sheet模板实施。**本节替代2026-11-09的昼夜间导出规则**：不再提供“导出昼间作业”和“导出夜间作业”两个按钮，不再截断导出时间。最新界面要求进一步收敛为单日导出，删除全选入口、预览及说明句。

实体关系核对：每日施工作业与危大工程信息登记共用原始作业记录。危大导出只读同一记录的危大段，按登记模块同一组危大字段识别；ID及原字段不变，不复制或新增业务实体。日期、表单选择、导出分组及统计都是内存中的导出配置/结果，不新增持久化字段，不修改登记模块。

### 入口、日期与文件

- 台账施工日期默认浏览器本地当天，保留清空能力。
- 工具栏统一“导出”按钮，使用平台下载图标。点击后打开“导出每日施工作业”弹窗，日期初始化为台账选择的施工日期。
- 弹窗只使用Element Plus单日期选择组件，一次只能选择某一天，再次选择会替换原日期，日历选日后自动收起。弹窗改日期不改台账筛选。
- 必须选择一个日期及至少一种表单。台账日期清空时，必须在导出弹窗明确选择日期，不能隐式导出全部历史；无日期或无表单时禁用“确认导出”。
- 每次打开默认同时勾选“夜间作业、危险作业、危大工程”三项，分别允许取消或勾选；删除独立的“全部导出”复选框。
- 删除整个“导出预览”，以及多日打包、时段说明、关键词回显、空结果说明、表单描述和文件格式提示等说明性句子。危大工程接入实际数据后移除“模板示例”标签。
- 每次仅生成一份 `每日施工作业_YYYY-MM-DD.xlsx`，内含所选的1～3张Sheet；页面不再提供多日选择或ZIP下载。
- 弹窗按整个浏览器窗口水平、垂直居中，移除固定顶部偏移；弹窗和日历不会撑出外层页面滚动条。小窗口需要滚动时仅允许弹窗正文内部滚动，背景台账保持位置和宽度。
- 选中的夜间/危险作业Sheet没有符合记录时，仍保留模板标题、表头及零统计。危大工程无匹配记录时仅保留标题和12列表头，不残留示例，不另增模板没有的统计尾行。
- Sheet按“夜间作业、危险作业、危大工程”的规定顺序输出，标题前按实际选中的表单连续编号1～N，不按原模板编号跳号。只选危险作业与危大工程时，标题分别为“1建设…”和“2建设…”；只选一张时均从1开始。

### 取数与时间

| 表单 | 导出日期D对应的判断区间 | 原始施工日期取数 | 纳入记录 |
| --- | --- | --- | --- |
| 夜间作业 | D日20:00（含）至D+1日07:00（不含） | D、D+1两天 | 区间内所有有有效重叠的作业，包括“不涉及危险作业”的普通作业 |
| 危险作业 | D日00:00（含）至D+1日00:00（不含，即24:00） | D日 | 与全天有有效重叠且按既有规则属于危险作业的记录 |
| 危大工程 | D日00:00（含）至D+1日00:00（不含） | 登记模块同源记录，不按开始日期预先截断 | 危大段起止时间与所选日期全天有有效重叠的记录，包括此前已开始、当日仍在施工的跨日记录 |

- 用作业开始/结束时间与目标区间的**严格正时长交集**判断是否纳入。仅接触20:00或次日07:00端点、零时长、倒序、缺失或无效时间不纳入；不修复不符合原填报日期规则的历史记录。
- **交集仅用于筛选，Excel中的原施工字段、开始时间、结束时间、类别、联系人、手机号和措施均保留原值，不裁剪、不脱敏、不补齐午夜间隙。**
- 例如导出6月30日夜间：6月30日18:00～21:00、7月1日00:00～08:00均纳入，Excel仍显示18:00～21:00、00:00～08:00；标题和统计归属日期都是6月30日。
- 夜间与危险作业Sheet可以包含同一条源记录，两个Sheet分别统计，不要求互斥。
- 除弹窗明确选择的日期外，沿用台账关键词条件，匹配项目、施工单位、区域、类别和管理单位，不限当前页。夜间从完整台账扩至次日，不能直接使用仅含D日的可见列表。
- 危大工程类别匹配登记的`majorProjectCategory`，起止时间使用`majorStartTime`、`majorEndTime`，不使用同一记录的危险作业时间。使用与目标日期的有效交集筛选，不调用COC看板“当日无数据回落到最近填报日”的演示逻辑。
- 当前是纯前端Mock实现；未来接入后台时，夜间取数必须同样覆盖D、D+1两日并保留其他筛选条件。
- 每日施工作业原填报校验保持：起止时间均属于施工日期当天00:00～23:59，开始不晚于结束，不支持跨日填写。危大工程登记既有校验不改，其独立起止时间可覆盖多天。原内部夜间识别逻辑不改，本次20:00只用于导出区间。

### 模板、合并与统计

用户确认的源文件：

`E:/Documents/1Files/seewintech/perwork_daily/261111/模板-每日施工作业计划表-yyyy-mm-dd.xlsx`

项目内只读资源副本为 `src/assets/daily-work-templates/export-plans.xlsx`，SHA256：

`1787ac679527a94fe082a9efd1b0ba4d222597c9cbf9db91c5867d0b12cef641`

- 源文件没有改写；副本保留模板字体、边框、列宽、表头格式，夜间及危险作业使用16列：序号 + 原有15个业务字段。标题第1行、表头第2行、实际数据第3行起，最后一行为合并的统计说明。
- 危大工程使用模板12列：序号及登记的11个业务字段。字段由`MAJOR_WORK_REGISTER_FIELDS`映射，标题第1行、表头第2行、数据第3行起；按项目分组并合并对应序号、项目名称，组内管理单位相同才合并，不增统计尾行。
- 原导入模板仍保持既有结构，本次16列仅适用于新增导出模板。
- 按原项目名称分组，合并同项目序号和项目名称；组内管理单位相同才合并该列，存在差异时逐行保留。其他字段不因分组而合并丢失。
- 数据行自动换行，保留模板最小行高并按内容增加；Excel单行高度按409.5磅上限处理，单元格全文保留。
- Sheet中的类别名称按实际危险作业记录去重列出。“不涉及危险作业”等既有非危险标识不计入危险类别数。
- 夜间统计的项目数和作业项数使用本Sheet全部实际导出行；“其中危险作业”的项目数、作业项数及类别数只使用其中的危险作业子集。
- 危险作业统计使用本Sheet实际导出行。项目数按项目名称去重；作业项数按记录行数计算，不能按合并后的序号数量计算。
- 每份文件的统计日期只使用该文件对应日期D，格式“x月x日”；夜间不受次日凌晨记录原施工日期影响。
- 所有Sheet先清除模板示例行，再填入实际结果。危大工程读取登记段原字段，跨日原时间、多名监管人员及措施均原样保留，不参与夜间或危险作业Sheet的统计。

统计尾行：

- 危险作业：`[日期]危险作业：[项目数]个项目共计[作业项数]项危险作业，涉及[实际类别名称]等[类别数]个类别。（备注：数据来源为各项目所报危险作业计划，实际危险作业可能有所调整。）`
- 夜间作业：`[日期]夜间作业计划：[项目数]个项目共计[作业项数]项作业，其中危险作业[危险作业项目数]个项目[危险作业项数]项，涉及[实际危险作业类别名称]等[类别数]个类别。（备注：数据来源为各项目所报危险作业计划，实际危险作业可能与计划有出入，需晚上指挥部研判会时与各项目部进一步确认。）`
- 无类别时显示“涉及0个类别”，不输出空名称或“不涉及危险作业”类别。
