# 深圳机场扩建工程信息化平台

基于 Figma「后台UI规范」实现的机场工程项目管理一体化前端，整合 COC 调度大屏与后台管理模块。

> **协作同事先读**：[同事协作指南-Git拉取与同步.md](同事协作指南-Git拉取与同步.md) —— 首次克隆、日常拉取/提交/推送、同步范围红线与常见错误处理，文末附可直接交给 AI 执行的指令块。

## 技术栈

- Vue 3 + Vite
- Element Plus
- Vue Router
- ECharts

## 启动

```bash
npm install
npm run dev
```

## 打包

```bash
npm run build              # 标准 Web 构建
npm run build:html         # 默认：一个 HTML（后台 + 内嵌 COC 大屏）
npm run build:coc-html     # 可选：仅当需要独立大屏文件时再执行
```

产物目录：`release/`。日常演示只跑 `build:html` 即可，打开后经顶栏或 `#/coc` 进入大屏。

## 已实现模块

- 后台整体布局（顶部导航 + 左侧菜单 + 主内容区）
- COC 调度大屏（指挥部 / 项目视图 / 项目调度）
- **质量验评（QM-INSPECT）**：目录树/表单库/检验批类型/单位本级资料、验收计划编制复核、检验批·分部分项·单位·专项·竣工验评（填报/审批链/整改复验）、统计看板、App 审批待办（前端 Mock，字段对齐 PRD V1.10 / 数据模型 V1.16）
- 安全管理 · 劳务管理（看板、实名、考勤、预警、轨迹、设备等）
- 安全管理 · 车辆管理（看板、台账、通行、轨迹、预警等）
- 视频监控 · NVR 设备管理与监控页面

## 每日调度检查

工程指挥部 → 调度中心 → 每日调度检查，页面地址为 `#/coc-admin/daily-dispatch-check`。提供每日检查、检查统计、统一调度填写、项目部两类独立填写和只读详情。项目调度标签在既有项目信息管理中配置。

使用浏览器 IndexedDB 保存原型数据、图片、模拟占用和日志；尚未接入真实后端。功能来源、需求资料和验证方式见 [每日调度检查说明](docs/features/daily-dispatch-check/README.md)。

## 处罚单台账与导出

调度中心 → 处罚单（`#/coc-admin/penalty`）提供关键字、状态、关联项目施工单位筛选及分页。处理中、待验收、非手动关闭的处罚单按用户提供的三份 Word 模板导出，填入项目名称、下发日期、对应处理信息和补充图片。字段来源、状态操作及验证方式见 [处罚单说明](docs/features/penalty/README.md)。

## 任务单执行人回复

调度中心 → 任务单（`#/coc-admin/notice`）下发后进入“处理中”，执行人通过我的待办回复“已执行”或“无需执行”。任一执行人首次成功提交后结束流程，已办只归实际处理用户，其他执行人的待办移除。详情、字段来源、旧数据处理及当前验证进度见 [任务单回复说明](docs/features/dispatch-task/README.md)。
