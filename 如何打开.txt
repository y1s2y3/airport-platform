工程建设智慧管控一体化平台

一、推荐：双击演示
打开 release\机场工程项目管理平台v2.html，无需安装 Node 或启动服务器。
不要直接双击工程目录的 index.html 或 app.html；它们是开发入口。

二、开发预览
安装 Node.js 22.12+ 或 24，在本目录运行 npm ci，再运行 npm run dev。
默认地址：http://localhost:5173 。端口占用时运行 npm run dev -- --port 5174。
脚本必须保留 --configLoader native；受限环境打开浏览器失败时可手工访问上述地址。

三、演示入口
项目级：工作台/个人中心，所属模块选择巡检管理。
我的待办、我的已办、我发起的：八类整改流程示例；巡检任务执行三条。
我的待办整改、复查行：处理旁的指派按钮。
我的已办：指派记录、三组指派示例；抄送我的：整改单抄送示例。
建管APP：项目级左侧菜单，或 #/app/login。

四、构建
npm run build       标准构建，输出 dist。
npm run build:html  更新 release 下的单文件演示入口。
